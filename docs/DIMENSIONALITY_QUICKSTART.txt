# UMMBAS Dimensionality Experiment - Quick Start Guide

## Overview

This experiment investigates how the **dimensionality of the similarity space** affects the performance of different dimensionality reduction methods (PCA, UMAP, t-SNE) for virtual screening.

**Key Question:** Does higher dimensionality improve or hurt screening performance?

## Experimental Design

- **Target Protein:** ABL1 (same as hyperparameter sweep)
- **Representation:** Physicochemical features only
- **Methods:** PCA, UMAP (Euclidean), t-SNE
- **Dimensions:** 2, 3, 5, 10, 20
- **Strategy:** Co-embedding only (as specified)
- **Hyperparameters:** Best values from Experiment 1 (UMAP: n_neighbors=500, min_dist=0.01; t-SNE: perplexity=1000)
- **Replicates:** 5 random seeds (42-46)

## Key Differences from Other Experiments

1. **Same target as Experiment 1** (ABL1) - but testing different dimensions
2. **No hyperparameter tuning** - uses optimal values already identified
3. **Only co-embedding strategy** - projection not tested
4. **Multiple dimensions per run** - each job processes all 5 dimensions

## Quick Start

### 1. Generate Configuration Files

```bash
python generate_dimensionality_configs.py
```

This creates 3 config files in `dimensionality_configs/`:
- `config_ABL1_features_pca_coembedding.json`
- `config_ABL1_features_tsne_coembedding.json`
- `config_ABL1_features_umap_euclidean_coembedding.json`

**Note:** Each config contains `"simspace_dims_to_test": [2, 3, 5, 10, 20]`, so each job automatically processes all dimensions.

### 2. Submit Jobs to HPC

```bash
bash hpc/submit_dimensionality_jobs.sh
```

This submits:
- 3 configs × 5 seeds = **15 total jobs**
- Each job processes 5 dimensions internally
- Total analyses: 15 jobs × 5 dimensions = **75 analysis runs**

Expected runtime: ~12-24 hours per job (depending on load)

### 3. Monitor Jobs

```bash
# Check job status
squeue -u $USER

# Check specific log (replace JOBID)
tail -f slurm_logs/DIM_config_ABL1_features_pca_coembedding_seed42_JOBID.out
```

### 4. Aggregate Results

After all jobs complete:

```bash
python aggregate_dimensionality_analysis.py \
  --workspace experiment_workspace_dimensionality/ \
  --output_dir final_report_dimensionality/
```

## Key Figures

### Primary: EF@1% vs Dimensionality

The main output is a **line plot** with:
- **X-axis:** Dimensionality (2, 3, 5, 10, 20)
- **Y-axis:** Mean EF@1%
- **Series:** Three lines (PCA, UMAP, t-SNE)
- **Error bars:** 90% confidence intervals

This plot directly answers the research question about dimensional impact.

## Integration with Other Experiments

This experiment is **independent but complementary**:

1. **Uses data from Experiment 1:** Same ABL1 target, same data splits
2. **Uses hyperparameters from Experiment 1:** No re-optimization needed
3. **Compatible with existing pipeline:** Uses same `main_orchestrator.py`
4. **Unique workspace:** `experiment_workspace_dimensionality/` doesn't interfere with others
