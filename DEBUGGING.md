III. Integration Testing
These tests involve running scripts sequentially, using outputs of one as inputs to the next. The calls will be similar to the component tests but chained.
Example chain:
Run prepare_data.py -> get raw_target_ligands...csv, filtered_chembl...csv, filtered_zinc...csv.
Run calculate_features_and_fingerprints_exp.py on raw_target_ligands...csv -> get processed_target_ligands...csv.
Run calculate_similarityspaces_exp.py with filtered pre-calc files and processed target ligands (for t-SNE path).
Run project_and_analyze.py with outputs from step 3.
